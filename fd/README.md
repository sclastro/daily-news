# 定期存款追蹤器 💰

一個純前端、離線可用嘅小程式，用嚟記錄你嘅（美元／港元）定期存款，
自己手動輸入美元兌港元匯率，計港元總資產同每筆價值，仲會提你邊筆快到期。
**所有資料只存喺你部手機瀏覽器（localStorage），冇任何外接資料庫，冇上傳。**

## 功能

- 每筆定期記錄：**銀行名稱**、**金額**、**貨幣（USD／HKD，預設 USD）**、**到期日期**（必填），
  以及**開始存款日期**、**存款期限**、**年利率**、**計息基礎**、**預期利息**、備註（選填）。
- 手動輸入美元→港元匯率（例如 `7.8`）；港元總資產同每筆港元價值即時換算。
- **預期利息**：填年利率就自動計到期利息，公式係單利
  `本金 × 年利率 × 存期日數 ÷ 一年日數`。存期日數由「開始存款日期 → 到期日期」計；
  若冇填開始日期，就用到期日期倒推「存款期限」。每筆可揀 **360 或 365 日**基礎
  （**預設 360**，因為美元定期多數銀行用 360 日制；港元定期通常用 365，記得改）。
  表單會同時顯示另一個基礎嘅金額，方便對住銀行存單揀啱。
  如果銀行報嘅利息同計出嚟唔同，可以喺「預期利息」欄手動填數覆寫。
  頂部會顯示**預期利息總額**同**到期本利和**（都係港元）。
- **到期提醒**：到期前 **7 日內** 會標示「快到期」並喺頂部提你；已到期會用紅色標示。
  可以撳「🔔 開啟到期提醒」，之後每次開 App 若有快到期定期，會彈手機通知。
- 只填「開始存款日期」＋「存款期限」而唔填到期日期，程式會自動幫你計到期日期
  （月份會夾實喺當月最後一日，例如 1 月 31 日 + 1 個月 = 2 月 28 日）。
- **JSON 備份／匯入**：底部「匯出 JSON 備份」、「匯入 JSON」（可合併或取代）。
  舊版備份檔案照樣讀到，冇利息欄位嘅記錄只係唔會計利息。
- 支援 PWA，可以「加去主畫面」當一個 App 咁用，離線都用到。

> 提醒機制備註：真正喺 App 關咗都彈嘅背景推送，需要伺服器先做到；
> 呢個純本地 App 嘅通知係喺你開 App 嗰陣先觸發。日常撳入嚟睇 + 快到期標示已經夠用。

## 點喺手機用（加去主畫面）

要「加去主畫面」變成 App，網頁要行喺 `https://`（唔可以淨係 `file://`）。
最簡單免費做法係開 GitHub Pages：

1. 去 GitHub repo：**Settings → Pages**。
2. **Build and deployment → Source** 揀 **Deploy from a branch**。
3. Branch 揀 `main`、資料夾揀 `/ (root)`，撳 **Save**。
   （呢個 App 喺 `main` 分支先用到；記得將呢個 branch 合併返去 `main`。）
4. 等一兩分鐘，用手機 Chrome 開：
   **https://sclastro.github.io/daily-news/fd/**
5. Chrome 選單 → **加至主畫面 / Add to Home screen** → 完成，之後喺主畫面撳個圖標就開到。

想試唔想開 Pages？直接用瀏覽器開個 `index.html` 都運作（淨係唔可以裝做 App、亦冇通知）。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 介面（含 CSS） |
| `app.js` | 全部邏輯 |
| `manifest.webmanifest` | PWA 設定 |
| `sw.js` | Service Worker（離線快取） |
| `icons/` | App 圖標（由 `scripts/gen-fd-icons.py` 產生） |

改版時記得將 `sw.js` 入面嘅 `CACHE` 版本號加一，等舊快取更新。
